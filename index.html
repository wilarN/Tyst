Encryption that works with anything, because it sits between you and the clipboard.
The project is kept in one big file for a reason. Check out the README.md for more information. It is always recommended to build the program from source.

What it does

Tyst encrypts text before it leaves your system, targeting a specific peer using their public key.

Incoming encrypted messages are automatically decrypted locally using your private key.

No accounts. No servers. Just your clipboard.

Why

Most platforms store, scan, and analyze your messages.

Tyst makes sure what you send is not readable plaintext, even if the platform logs everything.

How it works

Copy text → Tyst encrypts it for your selected peer.
Paste it anywhere → send the encrypted message.
Copy their reply → Tyst decrypts it for you and displays it in a popup above the message.

Security

Encryption is handled locally using libsodium.

Experimental, no identity verification. Vulnerable to MITM attacks.

Zero Interaction

No UI flow. Just copy.

Clipboard Based

Works with any platform instantly since it works using your clipboard.

Local Encryption

Nothing leaves your system unencrypted.

Lightweight

No servers. No accounts. No overhead.

Not Full-System Security

Tyst assumes your environment is secure. It does not defend against clipboard sniffing, malware, or compromised systems.

It protects message content from platforms, not from local threats.
